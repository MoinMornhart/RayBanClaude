Hilfe

  • App verbindet nicht? Handy und PC im selben WLAN? Unter Windows beim ersten Start die Firewall-Frage mit „Zulassen“ (privates Netzwerk) beantworten.
  • „Nicht autorisiert“? QR-Code neu scannen – das Token muss übereinstimmen.
  • Keine Antwort von Claude? Claude Code muss mit dem Befehl oben laufen; in Claude /mcp prüfen.
  • Brille streamt nicht? Meta-AI-App → Brille → Entwicklermodus an, Bügel öffnen, Brille neu starten.
  • Port belegt? Andere Claude-Sitzung mit RayBan Claude beenden oder RAYBANCLAUDE_PORT setzen.
